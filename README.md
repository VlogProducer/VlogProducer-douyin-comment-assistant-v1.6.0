# 抖音评论助手 v1.6.0

> **电脑网页端 Chrome / Edge 扩展，不支持抖音手机 App。** 识别、筛选和排序都在当前浏览器本地完成。

- **最新版（推荐）：** 本地发布版 v1.6.0
- 历史版本：[VlogProducer/douyin-comment-assistant](https://github.com/VlogProducer/douyin-comment-assistant)

## v1.6.0 更新亮点

- **评论关键词筛选：** 输入关键词，只显示正文中包含该词的评论。
- **IP 城市筛选：** 按抖音公开显示的评论者 IP 属地筛选。
- **昵称筛选：** 按评论者昵称筛选，支持输入昵称的一部分，可与关键词、IP 城市组合使用。
- **更可靠的重新扫描：** 点击后会显示扫描进度；若评论区尚未打开，会先打开再重新扫描。
- **更快且有退避的自动加载：** 快速模式改为约 0.8 秒起步的即时滚动；没有新评论时自动逐步放慢，避免持续高频触发。
- **切屏恢复：** 切到后台或页面被冻结前，会保存最近整理的评论及自动加载状态；后台自动加载额外以浏览器允许的最小 30 秒周期做一次正常滚动唤醒，返回页面或浏览器恢复该标签页后自动续接。
- **定位不收起：** 定位原评论或展开回复后，助手面板仍保留在原位，并标记刚定位的卡片。
- **降低页面负担：** 只监听评论容器的变化；没有新增或属性变化时不重绘整个助手面板。

完整变更请参见 [CHANGELOG.md](CHANGELOG.md)。

## 基础功能

- 热度排序，以及最新 / 最早时间排序。
- 自动或手动加载更多评论，可调整自动加载速度。
- 从助手卡片定位抖音原评论，并展开评论回复。
- 面板支持移动、缩放和收起，并自动记住位置与尺寸。
- 仅识别真实评论区，排除视频标题、播放器文字和相关搜索。

## 安装（Chrome / Edge）

1. 打开扩展管理页：Chrome 输入 `chrome://extensions`，Edge 输入 `edge://extensions`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择解压后的扩展文件夹，确认文件夹内直接包含 `manifest.json`。
5. 建议把“抖音评论助手”固定到浏览器工具栏。

## 使用

1. 点击浏览器工具栏中的扩展图标。
2. 粘贴完整抖音视频链接，选择热度或时间排序。
3. 点击“打开视频并整理评论”。
4. 如果评论区没有自动打开，请手动点击抖音评论按钮。
5. 可输入“评论关键词”“IP城市”或“昵称”；三项可同时组合筛选。
6. 点击“自动加载”继续收集评论，也可以使用“手动加载”或亲自滚动原评论区。
7. 点击评论卡片右下角，可以定位原评论或展开回复。

## 重要限制

- 排序和筛选范围是网页中已经加载的评论，不代表视频的全部评论。
- IP 城市来自抖音公开显示的“IP属地”；没有显示属地的评论无法按城市命中。
- 昵称筛选基于评论卡片中公开显示的评论者昵称；若昵称重名，会同时命中这些评论者。
- 扩展不会绕过登录、验证码或抖音风控，也不会要求账号密码。
- 自动加载连续多次未发现新评论时会自动暂停；每批返回条数由抖音网页决定，扩展不会直接调用或绕过评论接口。
- 浏览器可能在内存紧张时彻底丢弃后台标签页；扩展会恢复已保存的数据和加载状态，但无法阻止浏览器级的标签页冻结或丢弃。
- 抖音网页结构更新后，评论识别规则可能需要同步更新。
- 请合理控制加载频率，并遵守抖音服务条款与适用法律。

## 隐私

本扩展没有服务器，不会上传评论或登录信息。所有处理均在当前电脑浏览器中完成。
