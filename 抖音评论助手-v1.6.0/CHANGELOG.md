# 更新日志

## v1.6.0

### 新增

- 新增按评论者**昵称**筛选：支持完整昵称或部分昵称，可与评论关键词、IP 城市组合使用。
- 自动加载支持切屏恢复：后台或页面冻结前会保存当前会话；浏览器恢复标签页后会尝试恢复面板和自动加载状态。
- 后台自动加载开启时，扩展会按照浏览器允许的最小安全周期进行一次正常滚动唤醒。

### 优化

- 快速模式使用即时滚动，避免反复等待平滑滚动动画；连续无新增评论时会逐步放慢并自动暂停。
- “重新扫描”增加进行中与完成状态提示；评论区未打开时会先尝试打开再扫描。
- 定位原评论或展开回复后，助手面板不再自动收起，并会高亮刚定位的评论卡片。
- 评论监听范围从整页收敛到评论容器；无新评论或属性变化时不再重绘整个面板，降低视频播放与评论加载时的 CPU 占用。

### 调整

- 移除不可靠的内部用户 ID（例如 `MS4w...`）展示与筛选。该值在部分抖音页面中并不能唯一标识评论者，现由更直观可靠的昵称筛选替代。

### 已知限制

- 仅处理抖音网页中已加载到 DOM 的评论，不代表视频全部评论。
- 单次返回评论条数由抖音网页控制；扩展不会调用内部评论接口、绕过登录、验证码或风控。
- 浏览器在内存紧张时可能彻底丢弃后台标签页；扩展会尽力恢复已保存状态，但无法阻止浏览器级冻结或丢弃。
